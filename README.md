# AI Daily

The repository will have AI News from LLM's to DevOps to Kubernetes. Total AI World in glimpse here..

Live at https://dailydoseofai.netlify.app

## Publishing an edition

Add `ai-daily-YYYY-MM-DD.html` (and optionally `AI-Daily-YYYY-MM-DD.pdf`) to the repo root and push.
`scripts/build.mjs` turns every edition into a front page, one page per story, desk (topic) pages
across editions, an archive and a search index. The newest edition becomes the homepage.

Site styles and scripts live in `site/`.
