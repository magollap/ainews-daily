Platform · Nov 12 · Private beta

Claude Managed Agents can now run entirely inside your own cloud

The Claude Platform release notes for Nov 12 add a self-hosted edition of Managed Agents. Until now only the sandboxes could be self-hosted. Now the whole service can: the agent server, a PostgreSQL store for agents, sessions and history, and the workers. Only model inference leaves your network, and it goes to whichever provider you choose. Anthropic is the default, and Help Net Security reports that Bedrock, Google's agent platform, Microsoft Foundry or an internal gateway also work. Credentials never enter the sandbox: a proxy pulls secrets from your own secrets manager and adds them to MCP tool calls. Network egress can be allowlisted and every agent action is logged for SOC review. Access is through your Anthropic account team, priced by quote.

Claude Code · v2.1.323 · Nov 12

Claude Code adds "Code Mode": the model writes JavaScript to call its tools

The newest Claude Code release adds Code Mode as an experimental opt-in. Instead of one tool call per turn, Claude writes a short JavaScript program that calls its tools, which can cut round trips on multi-step work. Admins can turn it off for a whole organization. Plugins get a version gate: engines["claude-code"] in plugin.json means out-of-range plugins won't install or load. claude plugin validate now type-checks TypeScript hook modules, with --strict to fail on warnings. Most of the changelog is security hardening: dozens of fixes to Bash permission matching (sudo/env wrappers, wildcard allow rules, rm checks from the wrong folder, Write/Edit ignoring Read-deny rules), a fix for auto mode starting with more permissions when unavailable, and sandbox fixes for config and checkpoint files.

Google · Nov 13 · Open source

TPU Sync: open-source library for fast KV-cache transfer on TPUs

Google released TPU Sync, a C++ library for moving KV caches and model weights between parts of a TPU deployment using direct asynchronous DMA, with no Python serialization. Google DeepMind · Nov 12, 18:00 UTC · GA

Gemini 4 Hydrogen: Google's fast, cheaper agent model, at $1.50/$7.50

Google released gemini-4-hydrogen, a closed-weights model adapted from Gemini 4 Carbon that Google calls its "daily driver for agentic workflows." It sits below Carbon and Argon. The 1,048,576-token window is shared by input, thinking and output tokens. Synchronous output is capped at 65,536 tokens and the knowledge cutoff is March 2026. Thinking levels are low, medium, high (now the default) and a new xhigh; "minimal" now returns an error. Google reports 51 on the Artificial Analysis Index at high and 54 at xhigh (Argon scores 50), 57% on Terminal-Bench 4.1 versus 18.2% for 3.8 Flash, and 2.5× faster task completion than 3.8 Flash. Google also claims more than 5× fewer fabricated claims and 2.3× better resistance to indirect prompt injection on Gray Swan's benchmark. On Agent Arena it ranks only #5.

IBM · Nov 12 · Apache 2.0 · 3B & 8B

Granite 4.1 LLMON preview: tagging prompt blocks cuts prompt injection to ≤5.6%

IBM replaced the usual chat template with LLMON (LLM Object Notation). Every block (system, instructions, data, documents, tool definitions, tool results) is wrapped and tagged with an "exec" permission, and only exec-authorized blocks count as commands. IBM's own tests show indirect prompt-injection success falling from 53–100% on baseline models to 0.02–5.6%. IBM warns this behavior is learned during training, not enforced by the system, so it shouldn't be the only defense.

PositiveA concrete, open format for separating trusted from untrusted input, which agents need.
NegativeSmall preview models. It's a learned behavior with no guarantee, and the results are internal only.
Why it matters
  1. Tool results such as web pages and CRM notes are the main injection path for agents.
  2. Small models like these work well as an injection-screening layer in front of your main model.
  3. Watch whether others adopt LLMON-style formats.
  4. Still sandbox and allowlist actions. Don't rely on the model alone.
  5. Voice agents that read caller-provided text benefit directly.

Solo.io · GA · reported Nov 13

Agent Substrate and kagent go GA; Substrate donated to CNCF

Solo.io made enterprise Agent Substrate (developed jointly with Google) and kagent generally available. Agent Substrate separates stateful agent sessions from active compute: idle agents are suspended and stored, then restored in under 500 ms. That lets clusters hold far more long-running agents than they have pods running. kagent handles building and operating agents on Kubernetes. The Substrate framework has been donated to CNCF.

Zyphra · Nov 12 · Apache 2.0

ZONOS3-Mini: open TTS with about 80 ms to first audio and voice cloning in 43 languages

Zyphra released ZONOS3-Mini, a sparse mixture-of-experts text-to-speech model with about 100M active and 800M total parameters, built on a hybrid Gated DeltaNet/attention design. It uses a new 15 Hz ZAC-1 codec that Zyphra says has about 10× lower word error rate than DAC-based open models. Reported numbers: 80 ms median time-to-first-audio and 457× real-time on an H100, and under 570 ms to first audio on a Pixel 9. It supports voice cloning, 43 languages, and control over accent, age and emotion. Training took 2.5 days on 112 H100s, and it ranks first among open-weight models on ZTTS2-Eval.

PositiveLatency in the range of commercial TTS, with Apache 2.0 weights you can self-host for free.
NegativeEasy voice cloning raises fraud and consent risks. The evaluation is Zyphra's own.
Why it matters
  1. 80 ms to first audio fits within a natural conversational turn.
  2. Self-hosting removes per-character TTS fees at scale.
  3. Fine-grained emotion control helps brand personas.
  4. On-device speed means TTS can run on the phone.
  5. Add consent checks and watermarking before enabling cloning.
Liquid AI · Nov 12 · Open

LiquidCodec: a 74M streaming speech codec that encodes 361× faster than real time on one CPU thread

Liquid AI's 24 kHz streaming codec uses 12 codebooks and parallel prediction. On a single CPU thread it encodes at about 361× and decodes at about 87× real time. It beat NanoCodec, Mimi and X-Codec 2 on ViSQOL, mel distance and TTS tests. It was trained on 264,000+ hours of speech in 107 languages with quantization-aware training, and works with Hugging Face Transformers.

PositiveEfficient enough for edge devices, and a strong building block for speech-to-speech models.
NegativeA component, not a product. Only useful if you train or fine-tune audio models.
Why it matters
  1. Cheap audio tokenization makes training your own speech-to-speech model more feasible.
  2. Fast on CPU means good codec quality on low-end devices.
  3. Wide language coverage helps multilingual agents.
  4. Streaming design lowers end-to-end latency.
  5. Compare against Mimi if you're building on Moshi-style stacks.

Research · Nov 13

WorldDraft benchmark: video models leak source cues in up to 64% of 4D renders

A new Hugging Face paper tests 12 video models on 432 paired 4D world-rendering tasks. It finds a trade-off: more structure in the prompt preserves the world better but lowers appearance quality, and conflicting inputs cause "source leakage" in up to 64% of cases. The authors also release WorldDraft-Primer, a visual prompting method that improves both on frozen models. No major new models from Kling, Seedance, HeyGen, Higgsfield or Runway were released in the window.
